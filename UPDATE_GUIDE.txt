MEK CLOUD MOBILE v0.3.0 - MESSAGING API

ATUALIZACAO
1. Extraia este ZIP.
2. No GitHub abra agendakingsound-dot/mek-cloud-mobile.
3. Add file > Upload files.
4. Envie TODOS os arquivos extraidos.
5. Confirme substituicao dos arquivos existentes e inclusao de message-store.js.
6. Commit direto na branch main com:
   MEK Cloud Mobile v0.3.0 - Messaging API
7. Nao clique em Reconstruir na Northflank. O CI/CD deve executar automaticamente.

DEPOIS DO DEPLOY
Crie no mesmo Secret Group da Northflank uma nova variavel:
API_TOKEN=<um segredo forte e diferente do ADMIN_TOKEN>

Nao publique nem envie esse token no GitHub.

TESTE DA API
GET /api/v1/status
Authorization: Bearer <API_TOKEN>

POST /api/v1/messages/text
Authorization: Bearer <API_TOKEN>
Content-Type: application/json
